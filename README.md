QuizMaster

QuizMaster is an Android quiz application developed using Kotlin and Jetpack Compose.It allows users to test their knowledge through different quiz categories and difficulty levels.

Features
- Multiple Quiz Categories
- Difficulty Levels
- Score Tracking
- Result Screen
- Statistics
- Dark/Light Theme

Tech Stack
- Kotlin
- Jetpack Compose
- Material 3
